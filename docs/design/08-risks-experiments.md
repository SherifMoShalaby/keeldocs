## 2. Validation experiments, priority-ordered (cheapest falsifiers of core assumptions first)

Ordering principle: each experiment falsifies a *load-bearing* assumption; run before or alongside the build, not after.

1. **E1 — Extraction recall/precision corpus** (~1 week, no product code needed beyond prototypes). Label endpoints/tables/env-vars in ~30 OSS repos per framework (NestJS, Express, Prisma). Falsifies: "the declarative tier covers the easy 80%" and "Express needs the code tier." Pass: table in R4. *If decorator-framework recall <90%, the two-tier provider thesis itself is wrong — redesign before building the engine.*
2. **E2 — History-replay harness** (~1–2 weeks; becomes permanent CI infrastructure). Replay 6–12 months of 5–10 real repos; compute anchor survival, drift FP/FN, re-anchoring events. Falsifies: "fact-hash drift is low-noise" (R1/R2), the product's core bet. Pass: survival ≥95%, FP <10% v0.1.
3. **E3 — Re-anchoring accuracy corpus** (piggybacks on E2 + synthetic refactors). Falsifies: "evidence-gated rebinding is safe." Pass: false auto-rebind <0.5%; thresholds per ADR-007.
4. **E4 — Lie-detector wow test** (~3 days with a prototype over E1's corpus + 10 users). Falsifies: "deterministic verification wows on first run" (R5 — the adoption bet). Pass: ≥60% commit starter docs; ≥8/10 confirm a finding.
5. **E5 — Determinism golden tests** (1 day to stand up; permanent). Falsifies: "byte-identical output is achievable across OSes." Pass: empty diff, 3 OSes × 2 runs.
6. **E6 — Redaction adversarial corpus** (~3 days). Falsifies: "the write barrier catches realistic leaks." Pass: 0 escapes, FP <2%.
7. **E7 — Agent adapter smoke matrix** (2 days; weekly thereafter). Falsifies: "Agent Skills standard actually yields cross-agent auto-invoke reliability" (the distribution bet; the standard's *uniform behavior* is the assumption, its existence is verified). Pass: green on 3 first-class agents.
8. **E8 — Scale benchmark** (after engine skeleton). Pass: budgets in R10.
9. **E9 — Noise SLO field trial** (v0.1 beta cohort, 4 weeks). Pass: accept-rate ≥30%, no user disables the nudge in week 1.
10. **E10 — Injection red-team** (before v0.2). Pass: R11.
11. **E11 — ERD scale rendering** (2 days). Pass: R13.
12. **E12 — Study verification** (half a day): obtain full text of "To Copilot and Beyond" (2026) to confirm/kill the "~46% / Continuous Documentation Synchronizer top-rank" claim before it appears in any positioning material.

Experiments E1–E4 together cost roughly three calendar weeks and can falsify the four assumptions the whole design stands on: extractability, low-noise drift, safe rebinding, and the zero-LLM wow. If any fails its threshold, the correct move is redesign, not adjustment of the threshold.
